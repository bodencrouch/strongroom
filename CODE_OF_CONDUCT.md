# Code of conduct

This project is a place to fix software. Keep what you say about the work: the code, the diff, the bug, the command that failed.

## What that means

- Argue with the artifact, not the person. "This function drops the field" is fine. A guess about someone's motives is not.
- Say what you checked. A claim with a command behind it carries more than a claim with a tone.
- Assume the other person is trying to get to a working result. Ask before you conclude otherwise.
- No harassment, slurs, threats, or posting someone's private information. That includes your own vault data.

## Where it applies

Issues, pull requests, discussions and any other space run for this project.

## Enforcement

The maintainer enforces this. Comments that break it may be edited or removed, threads locked, and people blocked from the repository. To report a problem, use GitHub's report option on the comment, or contact the maintainer through the profile at <https://github.com/bodencrouch>. Reports are handled privately.
