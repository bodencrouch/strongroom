# Strongroom artwork

The Strongroom icon is original artwork made for this project. It is a strongroom and staple on a teal rounded square. Source color: #0F766E.

- `Strongroom.icon/`: editable Icon Composer document and its glyph.
- `source/strongroom-glyph.svg`: foreground vector.
- `source/flat-icon.svg`: full icon. Every PNG below is rendered from this file.
- `macos/icon-{16,32,64,128,256,512,1024}.png`: default macOS icon sizes. The native build generates the asset catalog and ICNS used by the app and AutoFill provider.
- `../../apps/extension/public/icon-{16,32,48,128}.png`: browser toolbar icons.
- `../../apps/raycast/assets/icon.png`: Raycast icon.
